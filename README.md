Google Play Store Data Analysis (PySpark + Tableau)
 Project Overview

This project analyzes Google Play Store application data to uncover insights into app performance, user engagement, pricing strategies, and category trends. The goal is to support data-driven decision-making for a startup entering the mobile app market.

 Tools & Technologies

PySpark (Data Processing)
Python (Data Cleaning & Analysis)
Tableau (Data Visualization)
Jupyter Notebook
 Dataset

Google Play Store dataset containing information such as:

App names
Categories
Ratings
Installs
Reviews
Price
Size

 Data Processing Steps

Removed duplicates
Handled missing values
Cleaned numeric columns (Installs, Price, Reviews)
Converted data types using PySpark
Standardized inconsistent formats (e.g. “Varies with device”)

 Key Analyses

App category performance
Free vs Paid app comparison
Ratings vs Installs correlation
Price vs Installs relationship
Reviews as engagement metric
 Dashboards (Tableau)
Market Overview Dashboard
Performance Insights Dashboard
Final Insights Dashboard

 Key Insights

Free apps dominate the market
Higher reviews strongly correlate with installs
Price negatively impacts installs
Category plays a major role in app success

 Recommendations

Focus on freemium models
Target high-performing categories
Improve engagement to increase visibility
Optimize app size and performance
